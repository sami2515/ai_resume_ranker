# Project Demonstration Video

This folder is dedicated to the mandatory video demonstration (`demo_video.mp4`) showcasing the end-to-end functionality of the **AI Resume Ranker** recruitment platform.

## Video Demonstration Outline (Covering All Requirements)

1. **Authentication & User Management:** Recruiter registration, login, and secure session management.
2. **Resume Batch Ingestion:** Drag-and-drop resume upload (`.docx` / `.pdf`), content hash duplicate detection, and real-time processing status.
3. **Job Description Configuration:** Creating JDs, automated requirement parsing, and target skill extraction.
4. **Hybrid Ranking & Scoring:** Automated candidate scoring combining exact/synonym keyword matching with deep semantic sentence embeddings.
5. **Interactive Explainability Drawer:** Detailed breakdown of matched skills, missing skills, semantic score, and composite score calculation.
6. **Recruiter Feedback Loop:** Recording hire/reject decisions and triggering dynamic weight adjustments.
7. **Shortlist Export:** Exporting ranked candidates and candidate summaries in Excel and PDF formats.
8. **Recruitment Analytics Dashboard:** Visual metrics including hiring funnels, score distributions, and in-demand skills analysis.
